# Alpine Star frontend implementation

Next.js React static export with TypeScript, Manrope bundled locally via fontsource and editorial Georgia headlines. Uses generated local hero and expedition WebP photography. Brand foundation and UI handoff reflected in forest, ivory, orange tokens and natural hero negative space without a full-photo scrim.

Interactive features: five planned-capability tabs; custom SVG topographic phone route demo with zoom and recenter; functional preparation checklist; mobile menu; native accessible coming-soon waitlist dialog with no data collection. Semantic sections, reduced-motion support, responsive layouts, keyboard focus styles, eager hero and lazy expedition image.

App features and sample route values are explicitly illustrative. No fabricated reviews, live claims, or guarantees. Development files created through WSL. Root agent owns dependency installation and final build/browser accessibility verification.
